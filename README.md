# Starbucks Beverage Analysis Dashboard

## Project Overview
This project is an interactive **Power BI dashboard** built to explore Starbucks beverages and compare their nutritional characteristics. It focuses on beverage categories, calories, sugar, caffeine, beverage preparation type, and protein.

The dashboard is designed to help users quickly compare drinks and identify patterns across the beverage menu.

## Objectives
- Summarize the beverage dataset using key performance indicators (KPIs).
- Compare calorie levels across beverage categories.
- Explore how beverage categories contribute to the total number of beverages.
- Compare average caffeine content across categories.
- Identify beverages with higher calorie values.
- Filter the analysis by beverage preparation method and protein content.

## Dashboard Features
The Power BI report includes the following visuals:

- **KPI cards:** Total Beverages, Average Calories, Average Sugar, and Average Caffeine.
- **Line chart:** Calories by beverage category.
- **Donut chart:** Distribution of beverages by category.
- **Column chart:** Average caffeine by beverage category.
- **Bar chart:** Calories by individual beverage.
- **Slicers:** Beverage preparation type and protein content.
- **Visual elements:** Starbucks-themed images and dashboard background.

## Tools Used
- **Power BI Desktop** — data visualization and interactive dashboard development.
- **Power Query** — suitable for data cleaning and transformation before analysis.
- **DAX** — suitable for creating measures such as averages and beverage counts.

> Note: The report contains KPI measures and visual fields for these metrics. The exact data-cleaning steps and DAX formulas should be documented separately if they were used in the project.

## Key Questions This Dashboard Can Help Answer
1. How many beverages are included in the dataset?
2. What is the average calorie content of the beverages?
3. Which beverage categories have higher calorie values?
4. How does average caffeine content vary by category?
5. Which individual beverages have relatively high calories?
6. How can results be explored by preparation type or protein content?

## How to Use
1. Download or clone this project repository.
2. Open `Starbucks Analysis.pbix` in **Power BI Desktop**.
3. Use the slicers to filter the dashboard by beverage preparation type and protein content.
4. Select chart elements to cross-filter or explore related data points.
5. Hover over visuals to view available tooltips.
